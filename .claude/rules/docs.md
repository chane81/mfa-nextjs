# 문서 작성 규칙

이 저장소의 결과물은 기록이다. 문서는 "무엇을 했다"가 아니라 **"왜 그렇게 했고, 무엇이 아니었나"**
를 남긴다. 기각한 안과 오진 정정도 함께 남긴다 — 지우지 않는다.

## 어디에 쓰나

| 성격                              | 파일                                         |
| --------------------------------- | -------------------------------------------- |
| 회차 단위 작업 · 다음 할 것       | `docs/00-progress.md` (최신이 맨 위)         |
| 밟은 함정 · 재현 조건 · 해결      | `docs/05-troubleshooting/01-known-issues.md` |
| 설계 판단(채택 · 기각 사유)       | `docs/02-architecture/01-decision.md` (ADR)  |
| 계약 · 구조                       | `docs/02-architecture/0*.md`                 |
| 버전 고정 근거                    | `docs/03-setup/02-versions.md`               |
| 구조 도해(배포 · 런타임 · 번들러) | `docs/anatomy.html`                          |

같은 내용을 두 곳에 쓰지 않는다. 진행 기록은 요약 + 링크, 상세는 해당 문서에 둔다.

## `docs/anatomy.html`

경로와 순서를 보여주는 그림만 둔다. **근거·실측의 SSOT 가 아니다** — 각 절의 "근거 문서"
링크가 원본 마크다운을 가리키고, 수치는 거기서 가져온다. 설계가 바뀌면 마크다운을 먼저
고치고 그림을 따라 고친다. 반대로 하면 두 곳이 갈린다.

단독 HTML 이다. 외부 의존은 Google Fonts 하나뿐이고 스크립트는 둘 — 테마 토글과,
Pages 에서만 도는 `.md` 링크 재작성이다. 빌드에 들어가지 않으므로 라이브러리를 끌어오지
않는다 — SVG 는 손으로 쓴다.

`docs/` 는 `.github/workflows/pages.yml` 이 GitHub Pages 로 올린다
(<https://chane81.github.io/mfa-nextjs/anatomy.html>). 그래서 이 폴더에 새 파일을 놓으면
**공개된다**. Pages 는 마크다운을 렌더링하지 않으므로 해부도의 `.md` 링크는 그 자리에서
GitHub blob 주소로 바뀐다 — 상대 경로(`./02-architecture/…`)를 유지해야 그 치환이 먹는다.

## 형식

- 한글. 서술체. 표와 코드 블록을 아끼지 않는다.
- 로그 · 에러 메시지는 **실제 출력 그대로** 붙인다. 다듬지 않는다.
- 수치를 쓰면 측정 방법과 날짜를 같이 쓴다(`검증일: YYYY-MM-DD`).
- 고친 뒤 `pnpm format`. CI 가 `format:check` 로 막는다.

## 트러블슈팅에 추가할 때

본문 절만 넣고 끝내지 않는다. 맨 위 **"증상으로 찾기"** 표에 한 줄을 같이 넣는다 —
사람이 문서를 여는 시점은 증상을 보고 있을 때다.

앵커 링크는 GitHub 규칙으로 만든다: 소문자, 백틱 제거, **밑줄은 남는다**
(`` `_jsxDEV` `` → `#…-_jsxdev-…`). 밑줄을 빼면 링크가 죽는다(실제로 두 개 죽어 있었다).

**구두점은 사라지고 남은 공백은 각각 하이픈이 된다** — 그래서 구두점 양옆에 공백이 있으면
하이픈이 **둘** 나온다. 이걸로 다섯 개가 더 죽어 있었다(18차에 고침).

| 제목                         | 앵커                         |
| ---------------------------- | ---------------------------- |
| `A-10 을 또 밟았다 — 미등록` | `#a-10-을-또-밟았다--미등록` |
| `` `react-hooks@7` — 렌더 `` | `#react-hooks7--렌더`        |
| `` `/` 만 스켈레톤 ``        | `#0-6--만-스켈레톤`          |

손으로 세지 않는다. 문서를 고친 뒤 저장소 전체 링크를 한 번 훑는다 — 파일 존재와 앵커를
같이 본다. 마크다운의 `](...)` 를 전부 뽑아 제목에서 만든 slug 집합과 대조하면 된다.
