# 트리아지 라벨

스킬들은 다섯 개의 표준 트리아지 **역할**로 말한다. 이 파일은 그 역할을 이 저장소 이슈
트래커가 실제로 쓰는 라벨 문자열에 대응시킨다.

| mattpocock/skills 의 라벨 | 우리 트래커의 라벨 | 뜻                                          |
| ------------------------- | ------------------ | ------------------------------------------- |
| `needs-triage`            | `needs-triage`     | 메인테이너가 판단해야 하는 이슈             |
| `needs-info`              | `needs-info`       | 보고자의 추가 정보를 기다리는 중            |
| `ready-for-agent`         | `ready-for-agent`  | 명세가 다 됐다 — AFK 에이전트가 받아도 된다 |
| `ready-for-human`         | `ready-for-human`  | 사람이 직접 구현해야 한다                   |
| `wontfix`                 | `wontfix`          | 하지 않기로 한다                            |

스킬이 역할을 언급하면(예: "AFK 준비됨 트리아지 라벨을 붙여라") 이 표의 오른쪽 열
문자열을 쓴다.

쓰는 어휘가 달라지면 오른쪽 열만 고친다.
