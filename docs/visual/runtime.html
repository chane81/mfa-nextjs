host 와 remote 사이에서 벌어지는 일

화면 한 장이 서로 다른 저장소에서 따로 배포된 코드 셋으로 만들어진다. 그런데 브라우저는 host 도메인 하나만 안다 — remote 는 host 서버가 대신 불러다 실행해서 HTML 에 넣고, 브라우저는 hydration 할 때에야 remote 청크를 처음 받는다. 그 경로를 장면 단위로 재생한다.

이 그림이 주장하는 것

  • remote 가 SSR 된다. host 서버가 remote 의 node 타깃 번들을 받아 자기 React 를 주입하며 실행한다. 그래서 초기 HTML 안에 remote 마크업이 이미 들어 있다 — 스켈레톤이 아니라 내용이다.
  • 경계를 넘어도 소프트 내비게이션이다. 라우터를 하나만 두었기 때문이다. 라우팅은 host, 렌더링은 remote — 경계가 라우터를 가르지 않는다. / → /checkout 이동의 document 요청 증가는 0 (Multi-Zones 대조군은 1).
  • remote 하나가 죽어도 페이지는 산다. 독립 배포는 곧 독립 장애다. RemoteBoundary 가 그 패널만 에러 상자로 바꾸고 응답은 200 이다.
